# Ditwin design context

Ditwin is a city operations product for Laâyoune. Its audience is municipal prototype reviewers and technical operators. The geographic canvas leads; compact controls support water scenarios and road analysis. English UI with the city name Laâyoune; no locale switch is implemented.

The shared tokens in `web/static/workspace.css` own appearance: teal actions #0F766E, slate text #17212B, white panels, #F3F6F8 application surfaces, blue road selection. Plus Jakarta Sans headings, Inter body, JetBrains Mono values, with system fallbacks. The mirrored logo forms use dark teal, mint, white and sand. Preserve data provenance labels. Synthetic scenarios must remain identifiable.

Reuse native buttons, select fields, dialogs, shared showToast, visible focus rings and the existing responsive drawers. Motion is brief and respects reduced motion. Displayed 3D heights may be estimated. Road runs retain actual execution state; water controls require an explicit run after input changes. The map receives flexible remaining space; dialogs and panels own scrolling.
